# Iteration 组件

将文本输入分割为文本段落，并对每个段落迭代执行预定义工作流的组件。

---

**Iteration** 组件可以将文本输入分割为文本段落，并对其内置的组件工作流在每个段落上迭代执行。

## 适用场景

当需要工作流循环且循环次数*不*固定，而是取决于从特定 Agent 组件输出创建的段落数量时，**Iteration** 组件必不可少。

- 例如，如果您计划将多个段落输入 LLM 生成内容，每个段落各有侧重，一次性全部输入可能导致混乱或矛盾，那么可以使用 **Iteration** 组件（内部封装一个 **Generate** 组件）对每个段落重复执行内容生成过程。
- 另一个例子：如果您希望使用 LLM 将一篇长论文翻译成目标语言而不超出 token 限制，可以考虑使用 **Iteration** 组件（内部封装一个 **Generate** 组件）将论文分成小块，对每一块重复执行翻译过程。

## 内部组件

### IterationItem

每个 **Iteration** 组件包含一个内部 **IterationItem** 组件。**IterationItem** 组件既是 **Iteration** 组件内工作流的起点，也是其输入节点。它管理所有由输入创建的文本段落的工作流循环。

:::tip 注意
**IterationItem** 组件*仅*对当前 **Iteration** 组件封装的组件可见。
:::

### 构建内部工作流

您可以将其他组件拖入 **Iteration** 组件以构建内部工作流，这些"添加的内部组件"不再对当前 **Iteration** 组件之外的组件可见。

:::danger 重要
要从添加的内部组件中引用创建的文本段落，只需在该内部组件的 **Input** 部分中添加一个等于 **IterationItem** 的 **Reference** 变量。无需引用相应的外部组件，因为 **IterationItem** 组件管理着所有已创建文本段落的工作流循环。
:::

:::tip 注意
添加的内部组件在必要时可以引用外部组件。
:::

## 配置说明

### 输入

**Iteration** 组件使用输入变量来指定其数据输入，即要分割的文本。您可以为 **Iteration** 组件指定多个输入源。点击 **Input** 部分的 **+ 添加变量**包含所需的输入变量。输入变量有两种类型：**Reference** 和 **Text**。

- **Reference**：使用组件的输出或用户输入作为数据源。需要从下拉菜单中选择：
  - **Component Output** 下的组件 ID，或
  - **Begin input** 下的全局变量（在 **Begin** 组件中定义）。
- **Text**：使用固定文本作为查询。需要输入静态文本。

### 分隔符

用于将文本输入分割为段落的分隔符：

- 逗号（默认）
- 换行符
- 制表符
- 下划线
- 正斜杠
- 破折号
- 分号
