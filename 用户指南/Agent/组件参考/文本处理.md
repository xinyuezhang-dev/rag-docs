# Text processing 组件

合并或拆分文本的组件。

---

**Text processing** 组件用于合并或拆分文本。

## 配置说明

### 方法

- Split：拆分文本
- Merge：合并文本

### Split_ref

仅在选择 **Split** 方法时出现。

要拆分的变量。输入 `/` 快速插入变量。

### 模板

合并的模板。仅在选择 **Merge** 方法时出现。输入 `/` 快速插入变量。

### 分隔符

用于拆分或合并文本的分隔符。

### 输出

组件输出的全局变量名称，可以被工作流中的其他组件引用。
