# Message 组件

发送静态或动态消息的组件。

---

作为工作流的最终组件，Message 组件返回工作流的最终数据输出，并附带预定义的消息内容。如果提供了多条消息，系统会随机选择一条发送。

## 配置说明

### 状态码

整个工作流完成后返回的 HTTP 状态码（`200` ~ `399`）。*仅*当在 [Begin](./begin.md) 组件中选择 **Final response** 作为**Execution mode** 时可用。

### 消息

要发送的消息。点击 `(x)` 或输入 `/` 快速插入变量。

点击 **+ 添加消息**添加多个消息选项。当提供多条消息时，**Message** 组件会随机选择一条发送。

### 保存到记忆

将对话保存到指定的记忆中。展开下拉列表，可选择所有可用记忆或指定记忆：

![](../../../images/save_to_memory.png)

### 用户 ID

默认启用，表示是否通过用户 ID 将会话与 Agent 应用关联。激活后，可以在检索时定位与该 ID 关联的特定记忆。

:::tip 注意
RAGFlow 允许多个用户共享记忆。因此此功能与**保存到记忆**相关联。
:::
