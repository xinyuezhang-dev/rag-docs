# 提取目录

从文档中提取 PageIndex（即目录），以提供长上下文 RAG 并改善检索效果。

---

在索引过程中，此技术使用 LLM 提取并生成章节信息，将其添加到每个分块中以提供充分的全局上下文。在检索阶段，它首先使用搜索匹配到的分块，然后基于 PageIndex（目录）结构补充缺失的分块。这解决了分块碎片化和上下文不足所导致的问题，提高了答案质量。

:::danger 警告
启用 PageIndex 提取需要大量内存、计算资源和 token。
:::

## 前提条件

系统默认对话模型用于总结聚类内容。开始之前，请确保已正确配置对话模型：

![Set default models](../../../images/set_default_models.jpg)

## 快速入门

1. 导航到 **Configuration** 页面。

2. 启用 **PageIndex**。

3. 要在检索过程中使用此技术，执行以下任一操作：
   - 在对话应用的 **Chat setting** 面板中，打开 **PageIndex** 开关。
   - 如果使用 Agent，点击 **Retrieval** Agent 组件指定数据集并打开 **PageIndex** 开关。

## 常见问题

### 启用 `PageIndex` 后，之前已解析的文件会使用目录增强功能进行搜索吗？

不会。只有在启用 **PageIndex** 之后解析的文件才会使用目录增强功能进行搜索。要对启用 **PageIndex** 之前解析的文件应用此功能，必须重新解析它们。
