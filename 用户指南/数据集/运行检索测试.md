# 运行检索测试

对数据集进行检索测试，检查是否可以检索到预期的分块。

---

文件上传并解析后，建议在配置对话助手之前运行检索测试。运行检索测试绝*不*是一个多余或不必要的步骤！就像精密仪器的校准一样，RAGFlow 需要仔细调整才能提供最佳的问答性能。数据集设置、对话助手配置以及指定的大小模型都可能显著影响最终结果。运行检索测试可以验证是否可以找到预期的分块，帮助快速识别需要改进的方面或定位需要解决的问题。例如，在调试问答系统时，如果知道正确的分块可以检索到，就可以将精力集中在其他地方。例如，在 issue [#5627](https://github.com/infiniflow/ragflow/issues/5627) 中，问题最终被确认是由 LLM 的限制导致的。

在检索测试中，使用混合搜索检索通过指定分块方法创建的分块。此搜索根据您的设置，将加权关键词相似度与加权向量余弦相似度或加权重排序评分相结合：

- 如果未选择重排序模型，加权关键词相似度将与加权向量余弦相似度结合。
- 如果选择了重排序模型，加权关键词相似度将与加权向量重排序评分结合。

相比之下，从[知识图谱构建](./advanced/construct_knowledge_graph.md)创建的分块仅使用向量余弦相似度进行检索。

## 前提条件

- 文件上传并成功解析后才能运行检索测试。
- 必须先成功构建知识图谱才能启用 **Use knowledge graph**。

## 配置说明

### 相似度阈值

设置检索分块的门槛：低于该阈值的分块将被过滤掉。默认阈值为 0.2。这意味着只有混合相似度得分在 20 及以上的分块才会被检索到。

### 向量相似度权重

设置向量相似度在复合相似度得分中的权重，无论是与向量余弦相似度还是重排序评分一起使用。默认设置为 0.3，另一个组件的权重为 0.7（1 - 0.3）。

### 重排序模型

- 如果留空，RAGFlow 将使用加权关键词相似度和加权向量余弦相似度的组合。
- 如果选择了重排序模型，加权关键词相似度将与加权向量重排序评分结合。

:::danger 重要
使用重排序模型会显著增加响应时间。
:::

### 使用知识图谱

在知识图谱中，实体描述、关系描述或社区报告各自作为一个独立的分块存在。此开关表示是否在检索中添加这些分块。

该开关默认禁用。启用后，RAGFlow 在检索测试中执行以下操作：

1. 使用 LLM 从查询中提取实体和实体类型。
2. 使用提取的实体类型，基于 PageRank 值从图谱中检索 Top N 实体。
3. 使用提取的查询实体的嵌入向量，从图谱中查找相似实体及其 N 跳关系。
4. 使用查询嵌入向量从图谱中检索相似关系。
5. 通过将各实体或关系的 PageRank 值与其与查询的相似度得分相乘进行排名，返回 Top N 作为最终检索结果。
6. 检索最终结果中涉及最多实体的社区报告。
   *检索到的实体描述、关系描述以及 Top 1 社区报告将发送给 LLM 进行内容生成。*

:::danger 重要
在检索测试中使用知识图谱会显著增加响应时间。
:::

### 跨语言检索

要进行[跨语言检索](../../references/glossary.md#cross-language-search)，从下拉菜单中选择一种或多种目标语言。系统的默认对话模型会将您在 Test text 字段中输入的查询翻译为选定的目标语言。此翻译确保跨语言的语义匹配准确，让您可以检索到不同语言的相关结果。

:::tip 注意
- 选择目标语言时，请确保数据集中存在这些语言，以保证有效的搜索。
- 如果未选择目标语言，系统将仅以查询的语言进行搜索，这可能导致遗漏其他语言的相关信息。
:::

## 常见问题

### 启用 Use Knowledge Graph 开关时是否使用 LLM？

是的，LLM 将参与分析查询并从知识图谱中提取相关实体和关系。这也解释了为什么会消耗额外的 token 和时间。
