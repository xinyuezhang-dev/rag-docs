# 加速索引
import APITable from '@site/src/components/APITable';

加快文档解析和索引速度的检查清单。

---

请注意，某些设置可能会消耗大量时间。如果您经常发现文档解析耗时较长，可以参考以下检查清单：

- 在数据集的 Configuration 页面上，关闭 **Use RAPTOR to enhance retrieval**。
- 提取知识图谱（GraphRAG）比较耗时。
- 在数据集的 Configuration 页面上禁用 **Auto-keyword** 和 **Auto-question**，因为这两者都依赖于 LLM。
- **v0.17.0+：** 如果数据集中的所有 PDF 都是纯文本，不需要 OCR（光学字符识别）、TSR（表格结构识别）或 DLA（文档版面分析）等 GPU 密集型处理，可以在 **Document parser** 下拉菜单中选择 **Naive** 而非 **DeepDoc** 或其他耗时的大模型选项。这将大幅减少文档解析时间。
