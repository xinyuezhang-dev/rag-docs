# 共享 Agent

与团队成员共享 Agent。

---

准备就绪后，您可以将 Agent 与团队成员共享，使他们能够使用。请注意，Agent 不会自动共享；您必须手动启用共享，选择相应的 **Permissions** 单选按钮：

1. 点击目标 Agent 打开其编辑画布。
2. 点击 **Management** > **Settings** 显示 **Agent settings** 对话框。
3. 将 **Permissions** 从 **Only me** 更改为 **Team**。
4. 点击 **Save** 应用更改。

*完成后，团队成员将看到您共享的 Agent。*
