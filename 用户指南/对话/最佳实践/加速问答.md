# 加速问答
import APITable from '@site/src/components/APITable';

加快对话助手问答速度的检查清单。

---

请注意，某些设置可能会消耗大量时间。如果您经常发现问答耗时较长，可以参考以下检查清单：

- 禁用**Multi-turn optimization**将减少从 LLM 获取答案所需的时间。
- 将 **Rerank model** 字段留空将显著减少检索时间。
- 禁用**Reasoning**开关将减少 LLM 的思考时间。对于 Qwen3 等模型，还需要在系统提示词中添加 `/no_think` 来禁用推理。
- 使用重排序模型时，请确保有 GPU 进行加速；否则重排序过程会*极其*缓慢。

:::tip 注意
请注意，重排序模型在某些场景下是必需的。速度和性能之间总是存在权衡；您必须根据具体情况进行利弊权衡。
:::

- 禁用**Keyword analysis**将减少从 LLM 接收答案的时间。
- 与对话助手对话时，点击*当前*对话上方的灯泡图标，向下滚动弹出窗口查看每项任务的耗时：
