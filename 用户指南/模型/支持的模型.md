:::danger 重要

:::

## 示例：AI Badgr（OpenAI 兼容）

您可以通过现有的 OpenAI-API-Compatible 提供者将 **AI Badgr** 与 RAGFlow 配合使用。

要配置 AI Badgr：

- **Provider**：`OpenAI-API-Compatible`
- **Base URL**：`https://aibadgr.com/api/v1`
- **API Key**：您的 AI Badgr API 密钥（来自 AI Badgr 仪表盘）
- **Model**：任何 AI Badgr 对话或嵌入模型 ID，由 AI Badgr 的 OpenAI 兼容 API 暴露

AI Badgr 实现了 OpenAI 兼容的端点，包括 `/v1/chat/completions`、`/v1/embeddings` 和 `/v1/models`，因此 RAGFlow 无需额外的代码更改。

:::note
支持的模型列表摘自[此源码](https://github.com/infiniflow/ragflow/blob/main/rag/llm/__init__.py)，可能不是最新的。如需最新支持的模型列表，请参阅该 Python 文件。
:::
