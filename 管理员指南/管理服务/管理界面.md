# Admin UI

RAGFlow Admin UI 是一个基于 Web 的界面，提供全面的系统状态监控和用户管理功能。

## 访问 Admin UI

要访问 RAGFlow Admin UI，请在 Web UI 地址后添加 `/admin`，例如 `http://[RAGFLOW_WEB_UI_ADDR]/admin`，将 `[RAGFLOW_WEB_UI_ADDR]` 替换为实际的 RAGFlow Web UI 地址。

### 默认凭据
| 用户名              | 密码      |
|--------------------|----------|
| `admin@ragflow.io` | `admin`  |

## Admin UI 概览

### 服务状态

服务状态页面显示 RAGFlow 系统中所有服务的状态。

- **服务列表**：以表格形式查看所有服务。
- **筛选**：使用筛选按钮按**服务类型**过滤服务。
- **搜索**：使用搜索栏按**名称**或**服务类型**快速查找服务。
- **操作**（悬停在行上查看操作按钮）：
  - **额外信息**：在对话框中显示服务的附加配置信息。
  - **服务详情**：在对话框中显示服务的详细状态信息。根据服务类型，服务的状态信息可能以纯文本、键值数据列表、数据表或柱状图等形式展示。

### 用户管理

用户管理页面提供了管理 RAGFlow 系统中所有用户的综合工具。

- **用户列表**：以表格形式查看所有用户。
- **搜索用户**：使用搜索栏按邮箱或昵称查找用户。
- **筛选用户**：点击筛选图标按**状态**过滤。
- 点击**"新建用户"**按钮，在对话框中创建新用户账号。
- 使用**启用**列中的开关切换来激活或停用用户，更改立即生效。
- **操作**（悬停在行上查看操作按钮）：
  - **查看详情**：导航到用户详情页面，查看全面的用户信息。
  - **修改密码**：强制重置用户密码。
  - **删除用户**：确认后从系统中移除用户。

### 用户详情

用户详情页面显示用户的详细信息和该用户创建或拥有的所有资源，按类型分类（例如数据集、智能体）。
