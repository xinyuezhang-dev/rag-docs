# Admin 服务

Admin 服务是 RAGFlow 系统的核心后台管理服务，通过集中的 API 接口提供全面的系统管理能力，用于管理和控制整个平台。它采用客户端-服务器架构，支持通过 Web UI 和 Admin CLI 进行访问和操作，确保管理任务灵活高效地执行。

Admin 服务的核心功能包括实时监控 RAGFlow 服务器及其关键依赖组件（如 MySQL、Elasticsearch、Redis 和 MinIO）的运行状态，以及全功能的用户管理。在管理员模式下，可以进行关键操作，如查看用户信息、创建用户、更新密码、修改激活状态以及执行完整的用户数据删除。即使在 Web 管理界面被禁用的情况下，这些功能也可以通过 Admin CLI 访问，确保系统始终处于可控状态。

凭借统一的接口设计，Admin 服务将可视化管理与命令行操作的高效稳定性相结合，为 RAGFlow 系统的可靠运行和安全管理奠定了重要基础。

## 启动 Admin 服务

### 从源码启动

1. 启动 Admin 服务之前，请确保 RAGFlow 系统已经启动。

2. 从源码启动：

   ```bash
   python admin/server/admin_server.py
   ```

   服务将在配置端口上启动并监听来自 CLI 的连接。

### 使用 Docker 镜像

1. 启动前，请配置 `docker_compose.yml` 文件以启用 admin 服务：

   ```bash
   command:
     - --enable-adminserver
   ```

2. 启动容器后，服务将在配置端口上启动并监听来自 CLI 的连接。
